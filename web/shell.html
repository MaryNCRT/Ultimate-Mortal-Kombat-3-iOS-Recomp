UMK3 — prueba web experimental

Selecciona el archivo .ipa de tu propia copia. Esta página extrae directamente Payload/<app>.app/res/ y conserva las rutas y el contenido de cada archivo. No hace falta descomprimir el IPA ni elegir archivos uno por uno. Si ya tienes la app extraída, también puedes elegir su carpeta o directamente res. El IPA elegido se guarda en el almacenamiento local de este navegador para abrirlo automáticamente la próxima vez. No se envía a un servidor.

Comprobando si hay un IPA guardado en este navegador...
