## Ultimate Mortal Kombat 3 — PC port 0.0.7b alpha (Windows)

A launcher fix on top of [0.0.7](RELEASE-0.0.7-alpha.md). As before, **no game data and no game executable are included**: you compile the game from **your own** `.ipa` of UMK3 **1.2.59 for iPhone** with `UMK3-Launcher.exe`.

### Fixed in 0.0.7b
- **The UMK3 logo is built into the launcher.** A `logo.png` of your own in the game folder still replaces it.
- **BROWSE opens the file picker in fullscreen too** (the `.ipa` and the frame picture). On Windows a dialog owned by a fullscreen window opened behind it; the launcher now leaves fullscreen while the picker is up.

Everything in [0.0.7](RELEASE-0.0.7-alpha.md) is included; its known problems still apply.
